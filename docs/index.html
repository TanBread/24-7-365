Создан для эффективной сборки

В отличие от закрытых облачных песочниц, 7/24 IDE работает непосредственно в выбранной вами папке на вашем компьютере.

Прямой доступ к терминалу

Агент может запускать компиляцию, производить установку библиотек через `npm install`, настраивать базы данных и запускать скрипты сборки.

Абсолютная безопасность

Вы полностью контролируете действия ИИ. Настройте разрешения для чтения файлов, записи кода (с Ревью диффа перед записью) и запуска команд.

Снапшоты и Откат в один клик

Перед каждым шагом агент создает автоматическую точку восстановления файлов. Вы всегда можете мгновенно откатить весь проект назад.

Закрепление любимых моделей

Отмечайте звёздочкой до 3-х лучших моделей OpenRouter и мгновенно переключайтесь между ними с помощью кликабельных кнопок-тегов над чатом.

Превью в отдельном окне

Открывайте живое интерактивное превью вашего HTML-приложения во внешнем независимом окне, которое автоматически обновляется при редактировании кода.

Локально и приватно

Ваши проекты, переписка с ИИ и API-ключ хранятся локально на вашем ПК. Ключ шифруется системным хранилищем Windows DPAPI.

Безопасность ИИ-агента под вашим полным контролем

Мы считаем, что автономность должна быть безопасной. В 7/24 IDE вы сами настраиваете уровень доверия к ИИ:

  • Настройка разрешений на лету: Установите режим подтверждения для каждого типа операции: авто-разрешение, запрос подтверждения или полный запрет.
  • Визуальное Ревью диффов перед записью: Вы всегда увидите подсвеченную разницу (diff) кода, который агент планирует записать, и сможете отменить или одобрить изменения.
  • Песочница по умолчанию: Агент физически не имеет доступа к файлам за пределами выбранной вами рабочей папки. Полная безопасность вашей файловой системы.
Запрос разрешения на запуск

Агент запрашивает разрешение на выполнение команды терминала:

npm install chart.js --save

Быстрый старт за 2 минуты

Начать работу с ИИ-разработчиком невероятно просто.

1

Скачайте и установите

Скачайте установочный файл `.exe` для Windows с GitHub и запустите стандартную установку.

2

Выберите рабочую папку

При первом запуске выберите директорию на диске, где агент будет создавать и редактировать файлы.

3

Вставьте API-ключ

Вставьте ваш API-ключ OpenRouter в настройках, выберите нужную модель ИИ и начните творить.
