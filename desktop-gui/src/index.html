Провайдер

Выберите провайдера моделей ИИ для генерации кода. Вы можете использовать облачный сервис OpenRouter или локальный Ollama для оффлайн-работы.

Провайдер моделей Выберите между OpenRouter и Ollama
API-ключ OpenRouter Ваш ключ хранится локально и никуда не передаётся кроме OpenRouter
Адрес Ollama API Обычно Ollama работает локально на http://localhost:11434
Размер контекста Ollama: Лимит длины контекста для запросов к Ollama (num_ctx). По умолчанию 4096.
Статус подключения Не подключен

О программе

7/24 IDE

v1.3.7

7/24 IDE — автономный локальный ИИ-ассистент разработчика. Автоматически читает файлы, вносит изменения, запускает сборку и тестирует приложения в реальном времени.

Ключевые возможности:
  • Поддержка автономной работы через Ollama (полностью оффлайн)
  • Расширение инструментов через протокол MCP
  • Автоматические чекпоинты и возврат состояния в один клик
  • Интерактивный терминал с вводом stdin и отменой команд
  • Умные авто-коммиты в Git с AI-описанием изменений
  • Myers-LCS сравнение исходного и измененного кода с подсветкой
